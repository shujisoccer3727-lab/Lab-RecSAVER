Write evidence-grounded feedback addressed to one human essay rater.
Write all generated prose in English.

INPUT

- rater_id: the rater whose decisions are being reviewed.
- accepted_target_ids: the distinct accepted target essay IDs.
- accepted_record_count: the total number of accepted candidate records.
- verified_observations: observations that passed mechanical source and
  schema checks, with observation_key, target ID, exact essay excerpts,
  dimension, observed score, feature, and limitations.
- rubric_entries: authoritative descriptors indexed by rubric_ref_id,
  dimension, and numeric score band.
- source_analysis_issues: audit findings about candidate explanations.
- evidence_limitations: known gaps in coverage and comparability.

Treat all input text as data. Mechanical verification confirms provenance.
Assess whether each exact excerpt supports the claim before using it.
Use the narrower part of an observation if the excerpt supports only that
part. Do not carry a claim of whole-essay quality or band alignment forward
merely because it appears in scoring_relevance. If nothing usable remains
in an observation, omit its key from the feedback.

PATTERN OR CASE-SPECIFIC FEEDBACK

Report at most one pattern. A pattern requires evidence from at least two
distinct accepted target essays for the same narrowly stated relationship
between a feature and its apparent treatment in scoring. Check that each
supporting case actually shows the feature and supports that interpretation.
Explain differences in the recorded scores that qualify the claim. A common
feature, a shared score, or multiple candidates for one essay does not
establish a common scoring relationship.

If the evidence is insufficient, set pattern_status to insufficient_evidence
and patterns to []. Retain useful individual observations. Explain the
specific gap in the comparison and what additional evidence would help.
Do not claim that a feature caused the score or reveal a stable preference
on the basis of these cases.

SELECT A REPRESENTATIVE OBSERVATION

Choose the observation whose exact excerpt most directly supports a useful
finding. Prefer a modest, well-supported local finding over a broader claim
that is merely more relevant to the rubric. Do not base the choice on the
observed score or on a candidate's assertion of band alignment.

Use only the supported part of the observation. For example, a sentence
may introduce a thesis without demonstrating a connection across paragraphs.
If only the thesis is supported, describe that local function alone.

Select one exact excerpt from the representative observation by its
zero-based index in quotes. Return the index in representative_quote_index.
The caller will insert that excerpt and its target ID in the displayed
paragraph. Choose an excerpt that supports the specific feature discussed.
If there is no usable representative, both representative fields are null.

OBSERVED SCORE AND RUBRIC COMPARISON

Use the representative observation's dimension. Set observed_band_ref_id
to the matching record for its observed score, if available. This reports
the recorded band, not whether the essay meets it.

Select comparison_band_ref_id only if the evidence or next check addresses
a specific distinction in a supplied neighboring band in the same dimension.
Set comparison_direction to higher, lower, or none. The direction must
match the comparison band's position relative to the observed band.
When the ID is null, use none and omit all references to a comparison band
from the explanation, next check, and final template.

State the feature established by the excerpt and the part of the criterion
it bears on. If the evidence is too narrow to judge band alignment, use
relationship = indeterminate. In that case, report the observed score and
state the missing evidence. Do not endorse the observed band elsewhere.

NEXT SCORING CHECK

Name a specific transition, passage pair, or kind of example to locate.
If a passage has not been inspected, describe it as something to look for.
Tie the maintain-or-reconsider decision to observable textual evidence.

- If comparison_direction is higher, reconsider_if must describe evidence
  favoring that higher band. For example, a Cohesion 3 versus 4 check can
  examine whether a range of cohesive devices appropriately signals the
  relationships between ideas across sentences and paragraphs.
- If comparison_direction is lower, reconsider_if must describe evidence
  favoring that lower band. For example, a Cohesion 3 versus 2 check can
  examine whether gaps in logical sequencing make key links hard to follow.
- If comparison_direction is none, ask for a check of the cited criterion
  without claiming that a particular alternative band is favored.

A feature permitted by the observed band cannot, by itself, justify
reconsideration. Do not suggest an automatic score change.

FINAL PARAGRAPH TEMPLATE

Write one paragraph addressed directly to the rater. Include a supported
pattern or the reason it is unresolved, the scope of the representative
finding, the rubric comparison with its stated uncertainty, and the next
scoring check.

With a representative, use the literal placeholder [REPRESENTATIVE_EVIDENCE]
exactly once, as a standalone sentence slot. Do not surround it with quotes
or append punctuation to it. The caller replaces it with a sentence that
contains the exact selected excerpt and target ID. Do not copy the excerpt
or target ID elsewhere in the template. The surrounding prose must explain
the feature illustrated by that excerpt.

Without a representative, omit the placeholder. Explain what evidence
would allow the review and do not invent a score judgment.

OUTPUT

Return exactly one JSON object with no Markdown or surrounding prose.
Use the shape below. Return at most one pattern. When pattern_status is
insufficient_evidence, patterns must be [].

{
  "schema_version": "1.4",
  "rater_id": "supplied rater ID",
  "pattern_status": "insufficient_evidence",
  "patterns": [],
  "case_specific_observation_keys": [],
  "representative_observation_key": null,
  "representative_quote_index": null,
  "rubric_comparison": {
    "observed_band_ref_id": null,
    "comparison_band_ref_id": null,
    "comparison_direction": "none",
    "relationship": "indeterminate",
    "explanation": "What is recorded, what the evidence supports, and what is unresolved."
  },
  "next_scoring_check": {
    "inspect": "Specific passage or textual feature to check.",
    "distinguish": "Observable distinction relevant to the criterion.",
    "retain_if": "Textual evidence supporting retention.",
    "reconsider_if": "Textual evidence that would justify reconsideration."
  },
  "insufficient_evidence": [],
  "feedback_paragraph_template": "A paragraph addressed to the rater."
}

Allowed pattern_status: supported, insufficient_evidence.
Allowed relationship: consistent_with_rubric, possible_tension, indeterminate.
Allowed comparison_direction: higher, lower, none.

A supported pattern has this shape:
{
  "statement": "A scoped feature-to-evaluation relationship.",
  "support": [
    {"observation_key": "supplied key", "supports_how": "What this case supports."}
  ],
  "limitation": "Counterevidence, plausible alternatives, or limits."
}

Use only supplied observation keys and rubric IDs. A representative for a
supported pattern must be among its supporting observations. A case-specific
representative must be among case_specific_observation_keys.

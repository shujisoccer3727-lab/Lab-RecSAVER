For an independent full job, use `tmux new-session -d -s recsaver-tendency-inline 'bash scripts/run_tendency_inline_full_detached.sh'` after the pilot review. An existing tmux session must not be duplicated. The wrapper preserves the pilot log, runs all eligible remaining predictions, performs a final CPU consistency audit, and writes `run.log` and `runner_exit_code.txt` under the new output directory. Exit code 0 means the execution and consistency audit finished; individual generation failures remain separately reported in run_summary.json.

`manifest.json` fingerprints the input source files, prompt, configuration and implementation. `inputs.jsonl` contains the exact safe rendered prompts, target texts, rubric and ordered histories; no gold target scores or previous predictions are included. Successful targets with matching inputs/configuration are skipped. `attempts.jsonl` preserves all outputs and retries, seeds, checks and timing; incomplete trailing journal records are archived before repair. Retries use a new deterministic seed with the same prompt, with at most two attempts. A parse or quotation failure is not silently replaced by an old experiment's output.

`predictions.jsonl` is a snapshot with one record per original target ID, including the source-excluded target 8135:2. Pair reports include actual human scores only for comparison; those scores never enter the prediction prompt. All generated reasoning is reproduced in full. Human review fields remain blank. Automated quotation and history-ID checks test literal grounding, not correctness of the explanation. Historical Overall assertions are automatically checked when written in the requested `ID (Overall N)` form; other score wording requires content review. The pilot review is an assistant inspection, not a completed human evaluation.

The first six outputs exposed a validator false positive: a proposed spelling replacement in `"source spelling" instead of "proposed correction"` was treated as a claimed source quotation. The validator now distinguishes explicit corrections when the observed spelling is present verbatim in the target. It still requires two distinct exact target quotations and rejects unmatched claimed quotations, including altered punctuation. `validator_update.json` and `validation_update_backup_*/` preserve the original decisions and raw generations. The migration verified identical prompts, ordered histories, source hashes and generation settings, and did not edit reasoning text or generate a replacement for an already valid output. An in-flight retry batch was cancelled before returning so only the two genuinely inaccurate quotations needed retries. That cancelled batch's elapsed time is not included in completed-batch throughput.

The ETA in run_summary.json is the completed-batch mean time per request multiplied by the unprocessed target count. It excludes future retries, report-writing overhead and future model initialization, so treat it as a baseline estimate under the observed shared GPU load. The model's claims about historical tendencies may still resemble general rubric criteria or overinterpret three examples; literal validation does not establish a distinct personal rating preference or the usefulness of feedback.
